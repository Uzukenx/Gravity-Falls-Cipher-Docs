The solve for the season 2 collage was 
A1Z26->Atbash->Caesar 3

We will do one example to show the process


Ciphertext:
4-16-19 11-23-10 20-9-1-10-5-4-23-15-6-5 15-5 2-19-6-25 21-12-19-2-19-6

Step 1: A1Z26 
This cipher's name actually tells you exactly how it works 1=A 2=B 3=C…. 26=Z
So for our example 4=D 16=P 19=S etc.. which leaves us with
D-p-s k-w-j t-i-a-j-e-d-w-o-f-e o-e b-s-f-y u-l-s-b-s-f

We can remove the dashes
Dps kwj tiajedwofe oe bsfy ulsbsf


Step 2:Atbash
Another simple cipher technique where you layout the alphabet forward and backward

abcdefghijklmnopqrstuvwxyz
zyxwvutsrqponmlkjihgfedcba

We can now use this as a translation chart where you can find the letter in the top row and then look at the letter in the lower row a=z b=y c=x etc

So our cipher text goes from
Dps kwj tiajedwofe oe bsfy ulsbsf

To 

Wkh pdq grzqvwdluv lv yhub fohyhu 

Step 3: Caesar Cipher 3

How a caesar cipher works is you pick a number and use that number as a shift value. In this case the number used is 3. So if we have the letter A we would count 3 more letters and end up on D. One note is that if you have letter towards the end of the alphabet it loops back to the beginning so X for example would become A (note X=A is a hint carved on our tree in the Cheshire image)

Lets apply it to our cipher, but instead of encrypting the message we are now decrypting so we will not be going forward three letters but rather back three letters. 
W=T 
k=h
h=e
Etc.

Finally our plaintext is revealed: “The man downstairs is very clever”

Memoria
The “memoria technica” cipher essentially is what I would call a license plate cipher. The “Memoria Technica” cipher is basically like writing words in license-plate shorthand. Vowels don’t count, and Y is treated like a vowel, so you ignore them. 
For example: 
FAST → FST 
KEY → K 
EYE → nothing 
Then each remaining consonant corresponds to a number. Carroll gave each digit from 0–9 two possible consonants. 
So: KEY → K → 8 because K represents 8, while E and Y are ignored. 

Which is more of a funny coincidence to this photo because the word “key” encrypted becomes “8”. Another funny coincidence Carroll spoke of null words and specifically uses the word “eye” as an example word, which we also see carved in the tree.

Anyway you can see why this is a terrible cipher to decrypt. You lose so much of the original message that you can get multiple “answers”

Encrypting
Chain=Chn

Decrypting
Chn= Chin OR chain

So multiple answers exist, and there are no spaces so it’s pretty unforgiving. Now add the fact that we don’t know the reading order. 

Even if that happened to be correct it’s unlikely we could recover it.
